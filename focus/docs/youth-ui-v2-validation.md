## 延迟的实际口径

- 本轮 60 秒持续显示共 238 个样本确认，P95 约 **156 ms**。
- 含进入页面、暂停恢复与刷新重连的整套交互流程共 27 个确认，P95 约 **516 ms**。此口径尚未达到 300 ms 目标。
- 度量是「适配器收到样本 → 浏览器绘制机会后确认返回」的上限，含本机传输和确认时间，不含头环自身采样延迟。首次进入或恢复显示已有快照时，也包含该样本此前的年龄；不是纯渲染耗时。
- 动态指针的 150 ms 视觉过渡与文字读数更新分别处理；统计、有效期和真实样本数不受插值影响。

不能用持续显示的结果宣称所有场景、所有树莓派都已满足延迟目标。应在目标硬件分别测首帧、恢复和稳定运行。

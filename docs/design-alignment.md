## 2026-10-02：三区间直线指针与报告可读性（最新）

- 仪表盘改为固定的起步、专注、高专注三个色带，默认边界为 20 / 70。边界来自本场 `attention_thresholds`（启动配置的 `start_threshold` / `high_focus_threshold`），不再随当前读数改变长度。个人目标独立显示；区间展示平滑反馈，不替代基于原始样本的达标统计或安全检查。旧版后台未提供字段时兼容默认 20 / 70，修改阈值的部署需重启新版后台。
- 用深色径向直线替换箭头，随 0–100 平滑值转动，避免穿过中央数字；缺测隐藏指针、显示破折号。首页示意仪表同步为三区间直线样式。
- 报告采用三个核心指标、全宽回顾图、时间分布与阅读说明的层级。时间分布直接展示，不再藏在折叠区域；对比玩家时跟随蓝橙配色。保留原始/平滑两线、独立目标虚线、暂停及缺测区域，事件文字移到图下，避免竖排文字挤占曲线。
- 报告单个有效样本显示点标记；无读数或无有效时长显示具体说明。图表通过 ResizeObserver 跟随容器尺寸恢复，跨报告切换时释放旧图表，避免旧缩放和旧数据残留。回顾图提供“查看全程”按钮。对抽查的既有报告没有复现脚本报错，本次处理的是可确认的折叠可见性、稀疏数据和尺寸恢复问题。
- 实时曲线补充时间刻度、目标虚线；历史趋势可切换最长连续达标、达标时间占比、有效时长，增加最佳值标记、缩放和同条件统计卡片。中断、保存不完整、样本不足的历史记录保留断点。少于两次完整记录不评价趋势。
- 历史列表加入单人/双人/竞速图标、连续时长及中断提示。报告、历史、首页与训练页共用现有蓝白卡片、圆角和蓝橙玩家配色；报告与历史内容较多时允许纵向滚动。

验证：95 项 Python 测试通过；`test_visual_components.cjs` 验证固定三区间、配置阈值、0/50/100 直线方向及缺测；`test_report_charts.cjs` 验证单点、无数据、玩家切换、两张图尺寸、路由往返复用、缩放复位和三种历史指标。固定样例截图在 `reports/design-alignment/`，带“非实测”标记。完整模拟流程通过，无页面脚本错误及外部资源请求，结果在 `reports/ui-v2/browser-result.json`；本次 34 个确认样本的显示确认 P95 约 437 ms，仍高于 300 ms 目标。本轮不替代树莓派硬件和连续运行验收。

## 2026-10-02：仪表盘、赛车与曲线细化

- 仪表盘采用宽半圆、内部大数字、顶部目标值与两端 0/100 刻度；移除跨过数字的长指针，改用径向短箭头随读数移动。箭头、色带和数字读取同一个后台平滑值。达到个人目标后的进度段单独着色，缺测不画箭头。
- 蓝橙两辆小车改为带曲面高光、玻璃、轮胎和车身阴影的透明 PNG。本地文件位于 `web/static/assets/cars/blue-v3.png` 和 `orange-v3.png`，首页、比赛与成果页复用；[素材来源、使用方式与完整生成提示词](../web/static/assets/cars/README.md)。这是俯视渲染素材，并非运行时 3D 引擎；与参考图同类造型，不宣称像素级复刻。

## 页面与操作约束

- 800×480 是主要适配尺寸；首页、选择、准备、训练、竞速、成果、维护主页面及状态弹层均检查了页面边界。
- 教师设置的主要控件及保存按钮位于第一屏，昵称管理和更多设置在下方折叠区域；历史与详细报告按内容纵向滚动。
- 同时检查 1280×800 与 390×844，修复从大屏缩到窄屏时图表撑宽网格的问题。
- 插画、奖章、车型使用本地 SVG；曲线和指针使用本地 ECharts。人物保持同类风格，但不是将生成样图中的人物逐像素复制。
- 模拟与实机标识保留。手动开始、接管权限、刷新后暂停、急停锁定与复位后重新准备的规则不变。
- 教师设置折叠和时长选中效果只是界面反馈；保存仍由原后台接口校验，当前会话规则不会被修改。

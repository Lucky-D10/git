# 青少年版 Web 界面 v2

本版在现有 Python 后台上更新完整 Web 流程。采用设计稿中的浅蓝底、深蓝文字、白色卡片、蓝/橙双玩家、大仪表盘、草地赛道与运动小车。插画和赛车用本地 SVG 重绘，旧 Tk 入口继续保留。设计参考位于 `docs/design/youth-ui-v2/index.html`，实际读数和位置以后台状态为准。

## 打开和使用

```powershell
.venv/Scripts/python app.py web --mode simulation
```

在浏览器打开 `http://127.0.0.1:8000`。模拟模式需要主动指定，页面顶部和历史报告均显示模式。实机启动改用 `--mode hardware --config config/hardware.json`；缺失 SDK/GPIO 会报具体错误，不自动模拟。

训练流程：首页「专注训练」→ 单人/双人 → 选择昵称 → 检查头环连接、佩戴、校准、新信号 → 主动开始 → 统一倒计时 → 练习 → 暂停/继续或结束 → 本次收获 → 详细数据。

竞速流程：首页「小车竞速」→ 两位不同玩家 → 两路就绪 → 倒计时 → 两辆小车前进 → 本场结果。小车只向后台已确认的位置做短暂过渡，不在浏览器里计算胜负、延长计时或推算未来位置。成绩明确标为虚拟赛程。

首页选择活动时会请求本页操作权。刷新或断线会丢失权限；恢复后点击右上角「接管操作」，再明确继续。其他页面可只读观看。当前场次未结束时，再点活动入口会返回当前场次，避免误建新场。

## 页面分工

| 页面 | 展示与操作 |
| --- | --- |
| 首页 | 两个大入口、当前场次、成长记录、老师设置 |
| 人数与玩家 | 单/双人训练；昵称选择；头环编号、目标、时长预览 |
| 准备 | 分路显示连接、佩戴、设备校准、新信号；具体未就绪原因 |
| 单人训练 | 左侧动态指针仪表盘，右侧剩余时间、连续达标与鼓励卡，底部整行最近 30 秒曲线 |
| 双人训练 | 左右对称的各自仪表盘、目标、连续时间和曲线，共用倒计时与操作；不排名 |
| 竞速 | 蓝/橙 SVG 小车、后台虚拟进度、分路动力等级或缺测原因 |
| 状态覆盖层 | 倒计时、暂停、连接中断、急停、故障、结束；复位不会自动开始 |
| 本次收获 | 每人有效时间、最长连续达标、记录完整性、数据不足说明 |
| 详细数据 | 单独切换玩家，原始/平滑曲线、目标线和事件标记、区间有效时长、事件列表、CSV/JSON 导出 |
| 成长记录 | 昵称与 UTC 日期筛选；选择同条件组后显示该玩家最长连续达标趋势 |
| 老师设置 | 下一场时长、个人目标、体验/正式规则、虚拟赛道长度、减少动画；昵称与预设头像 |
| 设备维护 | 模式、控制/存储健康、头环状态、绑定、配置、版本、日志导出、释放控制权 |

学生核心页面按 800×480 验证，按钮可触摸；详细报告、历史和老师页面允许纵向滚动。窄屏自动调整布局。图标、文字和不同头像配合颜色表达状态。

## 数据与操作边界

- 仪表盘及短曲线显示平滑 Attention；原始值在详细报告中独立标注。达标比例、连续时间由后台根据原始有效样本及实际有效时长计算，前端不重新统计。
- 原来的固定黑色目标线改为动态箭头，0 指向左、50 指向上、100 指向右；目标值在独立标签中显示。初次显示直接指向当前值，后续最多 150 毫秒过渡。缺测隐藏箭头并显示检查头环提示，有效零值仍正常显示 0。减少动画设置和系统减少动态效果偏好均生效。
- 缺测及暂停处曲线断开。实时曲线只显示最近 30 秒，完整有效记录仍参与统计；不足两个有效样本时不显示平均值、达标比例或最长连续时间结论。
- 竞速页面的动力等级是后台归一化控制强度，不是 GPIO 实际 PWM 占空比。实体输出仍受配置中的上限和独立看门狗保护。
- 个人目标是练习参考，不是头环设备校准，更不代表智力或学习成绩。玩家昵称只在本机保存，不要求真实姓名。
- 教师预设只参与下次 `prepare`。运行、倒计时、暂停、急停/故障锁定时拒绝设置写入。每场配置快照继续保存在原有 `configs` 表中。
- 新增 `player_profiles` 和 `application_settings` 表，使用增量建表兼容既有数据库；昵称更新保留原玩家编号和历史关联。
- 普通操作保留请求编号并等待后台收据；结果不确定时重试同一请求。急停使用独立前端请求和后台优先队列，不被普通等待或满队列阻挡。同一控制步已排队的复位/开始不能抵消急停。
- 写入错误、记录不完整或保存中会明确显示。仅完整基础报告允许导出。新版不自动生成 AI 评价。

## 代码位置

| 文件 | 责任 |
| --- | --- |
| `web/static/index.html`、`style.css`、`design-match.css` | 页面结构、基础样式、设计稿对齐样式、响应布局和状态覆盖层 |
| `web/static/app.js` | 路由、用户意图、页面数据绑定与表单 |
| `web/static/js/connection.js` | WebSocket、心跳、权限、请求重试、显示确认 |
| `web/static/js/charts.js` | 可复用 ECharts 仪表盘、短曲线、回顾、分布、趋势 |
| `web/static/js/race.js` | 原生 SVG 车与后台位置的短时显示过渡 |
| `web/static/js/ui.js` | 图标、头像、提示、格式化、转义 |
| `web/static/js/illustrations.js` | 玩家形象、佩戴示意和鼓励卡的本地矢量插画 |
| `web/preferences.py` | 教师预设和昵称的校验、独立 API 工作线程持久化 |
| `deploy/kiosk_boot.py` | 独立于后台的浅色启动等待页，离线检查本地服务 |

所有脚本、ECharts、SVG、字体回退均可本地运行，无 CDN 或构建步骤；没有引入 React/Node 运行时依赖。FastAPI 继续静态提供页面，树莓派现有 systemd/kiosk 启动配置可复用，部署方法见 `stage3-web.md`。

## 验证与回退

```powershell
.venv/Scripts/python -m unittest discover -s tests
# 已安装 Playwright 时，先启动使用独立数据库的模拟服务：
$env:FOCUS_URL='http://127.0.0.1:8765'
node tools/test_web_browser.cjs
node tools/test_visual_components.cjs
# 连续运行；默认 7200 秒，可设置 FOCUS_SECONDS 做短时检查：
$env:FOCUS_SECONDS='7200'
node tools/soak_web.cjs
```

如果浏览器非 Playwright 自带 Chromium，可设置 `BROWSER_PATH` 为 Edge/Chromium 可执行文件；`PLAYWRIGHT_MODULE` 可指定已有安装路径。测试必须连接模拟服务，不能在正在使用的实机服务上运行。截图、测试结果写入 `reports/ui-v2/`；该目录不提交到 Git。

本次实际验收结果见 `youth-ui-v2-validation.md`。桌面模拟测试不能替代树莓派的 20 次冷启动、2 小时持续运行、断电存储恢复和实体急停验证。

改造前 Web 三个入口文件已备份到本机 `reports/ui-v2-baseline-20260929/`。部署时应保留完整旧发布目录，通过已有发布链接回退机制切换版本，并在停服务后备份数据库；不要仅回退一部分前后端文件。新增表为增量结构，不删除旧数据。

# 产品规则表（stage2-v1）

| 规则 | 体验模式 | 正式比赛 |
|---|---|---|
| 训练人数 | 开始前明确选择单人或双人 | 开始前明确选择单人或双人 |
| 双人竞速开始 | 两路都就绪，统一倒计时 | 两路都就绪，统一倒计时 |
| 单路无信号 | 该路动力归零，另一车道继续，记录该路 `device_transition` 和 `stale`/具体原因 | 同左 |
| 双路无信号 | 继续计时，动力归零，记录 `device_transition` | 中断本场并记录 `state_transition`，原因 `both_lanes_unavailable` |
| 手动暂停 | 动力归零，暂停时间不计入有效训练时间 | 同左 |
| 信号恢复 | 状态检查后恢复，持续奖励重新累计 | 同左 |
| 急停恢复 | 排除原因、人工确认复位，再重新开始 | 同左 |
| 成绩含义 | 报告同时标出虚拟成绩和 Attention 统计 | 同左 |

会话开始时冻结本表对应配置；报告保存规则版本、配置快照、配置摘要和事件日志，过程中不得修改判定标准。
